# REGRAS DE NEGÓCIO

## Handoff obrigatório para humano

Enviar para humano quando cliente falar:

- pix
- pagar
- pagamento
- sinal
- reservar horário
- marcar horário
- agendar
- fechar
- quero fechar
- pronto para fechar
- falar com Coringa
- chamar Coringa
- atendimento humano

## Não enviar para humano automaticamente

Manter IA quando cliente falar:

- quanto custa
- qual valor
- orçamento
- foto
- referência
- ideia de tattoo
- fechamento de braço
- piercing

## Funil obrigatório de orçamento

Antes de orçamento completo, coletar:

1. Nome
2. Tamanho em cm
3. Local do corpo
4. Referência ou ideia

Se faltar informação, fazer apenas uma pergunta por vez.
